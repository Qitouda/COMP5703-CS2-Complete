# 第二轮产品组任务单

负责人：曾博成。参与：傅饶、吴冬乔。状态：2026-09-20 工作稿。详细任务状态在[R2C 清单](../03_过程与交付/第二轮_交付任务清单.md)，本页说明交付责任，不表示已审核或已完成。

| 编号 | 交付 | 完成判断 |
|---|---|---|
| R2C-PM-01 | 第二次会议后的产品基线、三维范围、旧评分保留与不混算决定 | 团队理解同一产品定位；不存在 ICLR 新功能准入条件或“自动判欺诈”承诺 |
| R2C-PM-02 | 新可信度报告合同评审记录 | 分数、类别、来源、时间、不适用、未核实和技术失败的语义在三组一致；与旧 v0.4 合同分开 |
| R2C-PM-03 | Rubric、首批样本和验收路径审核 | 区分已决定产品原则与数据组待验证阈值；记录审核人、日期和版本 |
| R2C-PM-04 | 端到端验收、演示和遗留项 | 用真实论文与外部来源演示，任务表状态有证据；未解决的误报漏报和覆盖限制如实记录 |

产品组不替数据组编造学术判断准则，不替后端指定未经评估的算法；但必须阻止“文末检索不到＝虚构引用”“无代码＝欺诈”“issue 投诉＝已证实无法复现”等误导性产品表述。四档英文类别只描述风险发现；具体阈值由数据组提议后审核。低分单项不封顶总分，但必须在总分旁提醒。

本轮不重新设计旧五维评分，也不把旧分数塞进可信度报告。课程材料继续由傅饶统筹，各技术组对提供的事实和证据负责。原产品组 R2O 任务见[历史归档](../99_历史归档/第二轮_原产品组任务单_R2O.md)。

规范与阅读顺序见[第二轮文档说明](../00_项目总览/00_先读_第二轮文档说明.md)；本页只维护本组交付要求，进度以 R2C 清单为准。
