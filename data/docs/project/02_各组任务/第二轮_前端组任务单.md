# 第二轮前端组任务单

总负责人：曾博成；具体实现由傅饶、吴冬乔分配。执行人、日期与任务状态见[R2C 清单](../03_过程与交付/第二轮_交付任务清单.md)。

| 编号 | 任务 | 交付与验收 |
|---|---|---|
| R2C-FE-01 | 双模式入口 | 用户可分别选择旧论文评分或 **Check Credibility**；新模式不要求 ICLR；arXiv／PDF 输入、进度与返回路径清楚 |
| R2C-FE-02 | 可信度报告 | 总体类别与总分、三维小分数、低分提醒、逐条 Findings／Evidence、引用覆盖率和外部核查时间可读、可回查 |
| R2C-FE-03 | 真接口联调与回归 | 正常、显著问题、未核实、不适用、外部故障和无法评估状态正确；旧五维页面仍能使用 |

页面不自动展示旧五维分数，也不把两个分数混算。`No significant concerns found` 表示已完成的检查未见显著问题，不是“论文已被认证”；`Unable to assess` 是技术／输入状态，不是风险等级。第三方 issue 必须有原始链接和上下文，不以醒目红字掩盖作者回复或后续修复。无值不显示 0 分。

前端先画出新报告的信息层级与各状态，交后端确认字段、产品组确认文案，再做真实接口联调。旧 CSPaper 参考可用于局部可读性，不以大规模视觉改版替代本轮功能。原前端 R2O 任务见[历史归档](../99_历史归档/第二轮_原前端组任务单_R2O.md)。

规范与阅读顺序见[第二轮文档说明](../00_项目总览/00_先读_第二轮文档说明.md)；本页只维护本组交付要求，进度以 R2C 清单为准。
