## 最关键的交接

数据组先给“论文版本、应查问题、人工证据、预期状态和不适用条件”，后端再决定解析、工具调用、模型及校验的技术路径。产品组审核评分语义与范围，前后端根据同一份新合同联调。外部来源的可访问性与时间可能变化，所有真实报告都要带版本和核查时间。

各组不必等所有规则一次完成才开始：引用条目提取、公开 API 探测和双模式页面可并行；但总分、类别和“低风险”表述必须等数据规则及合同确认后接入。不得把静态样例、旧五维评分或论文录用结果当成可信度真值。
