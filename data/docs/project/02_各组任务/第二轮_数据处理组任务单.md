# 第二轮数据处理组任务单

负责人：赵龙翔，参与：刘文杰。具体执行人和日期统一在 R2C 清单填写。第二轮不以“旧五维分数与人工分差缩小”为主要交付，改为建立**可信度风险的人工作业标准和复评证据**。任务状态见[R2C 清单](../03_过程与交付/第二轮_交付任务清单.md)。

| 编号 | 任务 | 交付与验收 |
|---|---|---|
| R2C-DP-01 | 建人工核查样本 | 覆盖主张缺证／冲突、真实与有歧义的引用、公开／不公开代码、正负及无复现反馈，并包含正常对照；论文版本和来源可回查 |
| R2C-DP-02 | 校准并完善三维 Rubric | 明确不同 ML 论文类型的适用性、证据强弱、分值、权重、总分、四档类别、低分提醒；给后端可执行的边界案例 |
| R2C-DP-03 | 复评真实输出 | 记录重要问题漏报、正常论文误报、引用匹配错误、外部来源误关联、证据不支持结论及检查覆盖率；改进前后用同样本对照 |
| R2C-DP-04 | 新维度候选研究 | 对数字自洽性等提出样本、可检测证据、增量价值和误报风险；研究完成不等于正式加入评分 |

人工标注先于查看模型输出，关键争议由两名成员复核并保留各自判断。主张范围按 D-041 回退摘要／引言关键主张，去正文、图表和可取得的附录找依据；去重并记录排除理由、遗漏，不要求提取正文每条主张，也不以固定三条冒充完整。D-039 最低有效分保留，条目分值仍待校准；引用只验证文末条目对应文献的存在性，不读取全部被引全文；代码核查区分独立第三方评论与本团队亲自复现。

不预设未经验证的准确率目标。建议至少分别报告风险召回、误报、证据可回查性、引用检查覆盖率和“无法核实”的比例，并按不同论文类型观察偏差。产品组负责确认最终验收口径。记录使用[可信度核查样本与复评记录](../03_过程与交付/数据样本与%20Rubric/第二轮_可信度核查样本与复评记录.md)；旧五维差异模板保留在[历史归档](../99_历史归档/第二轮_原评估差异与优化验证记录_R2O.md)。

规范与阅读顺序见[第二轮文档说明](../00_项目总览/00_先读_第二轮文档说明.md)；本页只维护本组交付要求，进度以 R2C 清单为准。
