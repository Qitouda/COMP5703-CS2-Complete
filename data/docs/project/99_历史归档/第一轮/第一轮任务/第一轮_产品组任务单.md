# 产品组任务单（第一轮归档）

> 第一轮已于 2026-09-10 结束。本页保留第一轮任务定义；收尾见 [第一轮开发收尾](../第一轮_开发收尾.md)。当前工作见 [第二轮产品组任务单](../../../02_各组任务/第二轮_产品组任务单.md)，以 2026-09-14 更新方案为准。

## 小组成员

| 人员 | 角色 | 主要职责 |
|---|---|---|
| 曾博成 | 总负责人/产品/整合 | 确认 MVP 范围、优先级和验收标准；协调跨组工作并完成最终整合 |
| 傅饶 | 产品/前端 | 整理课程小组作业和提交材料；参与产品及前端协作 |
| 吴冬乔 | 产品/前端 | 从前端实现角度参与产品决策，并落实已确认的页面方案 |

产品范围、优先级和最终决策由曾博成确认。傅饶负责课程材料的整理与归档，但接口、字段、解析和测试等技术文档仍由对应技术组负责其正确性。

## 三周目标

产品范围、五维名称、字段结构和基础验收边界已经锁定。当前重点是管理分工与进度、处理影响产品范围的跨组问题，并准备课程提交和最终演示材料。

具体评估指标、评分锚点、证据规则、样本选择和评测方法由数据处理组完善。产品组只确认这些内容没有偏离已锁定的 MVP，不代替数据处理组编写学术评估规则。

## 需要其他组提供

- 前端组：页面进度、可演示版本、前端风险和验收结果。
- 后端组：接口状态、错误处理、联调结果和技术风险。
- 数据处理组：样本清单、完善后的 rubric、模型评测结果、质量检查记录和已知限制。
- 所有技术组：课程材料所需的准确技术内容，并确认相关事实。

## 需要交给其他组

- 已完成的 MVP 范围、字段合同、优先级和基础验收标准。
- 已确认的页面流程与 UI 方向。
- 跨组问题的最终决定、目标日期和演示要求。
